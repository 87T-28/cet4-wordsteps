# CET-4 WordSteps v1.0 需求规格（重建版）

日期：2026-10-10。来源：用户引用的 ChatGPT“开发思路”对话。

原聊天链接了同名 SRS 和开发计划附件，但当前目录和读取到的聊天没有附件实体。本文件整理已确认的方向，不声称复原原附件内容。以下具体数据接口与验收细节是本项目的实施约定，获取原附件后应复核。

## 1. 产品目标与约束

- 个人优先，少量朋友可使用；手机、电脑响应式体验。
- 支持游客本地学习，最终以邮箱验证码账号实现多设备同步。
- React + TypeScript + Vite；IndexedDB + Dexie；PWA；可替换 CloudBase v3 适配器。
- 现金预算目标 ¥0；不使用付费 API、托管或服务。不得保证免费云额度永久可用。
- 保留独立源码，未来采用 GitHub 管理、GitHub Pages 测试部署。
- 不实施微信/手机号登录、排行榜、复杂管理后台。

## 2. 页面需求

| 页面 | M0 基础结构 | 最终功能 |
| --- | --- | --- |
| 今日学习 | 任务入口、零记录概览 | 每日目标、新学/复习进度、继续学习 |
| 单词学习 | 自编示例词卡、释义切换 | 正式词库、发音、回忆评分、拼写测试 |
| 复习 | 没有学习记录的空状态 | 到期队列、间隔重复、错词巩固 |
| 词库 | 示例列表、中英文搜索 | 正式词库分类、搜索、词义与来源 |
| 统计 | 无记录的零值与正确率空值 | 新学/复习/正确率/连续天数/薄弱词 |
| 设置 | 临时学习计划预览 | 保存目标、导出导入、恢复与清理 |
| 账号 | 未接入说明、游客入口 | 邮箱验证码、退出、同步状态、注销 |

M0 不能把演示操作算作真实学习，不能展示虚构学习成绩或可用账号同步。

## 3. 词库与领域数据

- 单词使用稳定 ID，禁止数组索引作为永久 ID。
- 字段包括单词、音标、词性、中文释义、例句与翻译、标签、来源、数据版本。
- 正式词库优先评估 ECDICT；代码许可和词库许可分别核实，保留出处、许可证和处理脚本。
- 导入时检查重复 ID/词形、空释义、异常字段；提供版本、数量、数据来源报告。
- M0 的 6 个示例由项目自编，不冒充完整四级词表。
- 学习事件包含唯一事件 ID、wordId、deviceId、时间、主观评分、客观测试结果、schemaVersion。
- 进度包含上次/下次复习时间、间隔、连续正确次数、错误次数、算法版本。
- 存储设置、进度、事件、同步游标；事件追加与进度更新需要事务一致性。

## 4. 本地学习（M1）

- IndexedDB + Dexie 保存本机学习数据；刷新或关闭页面后可恢复。
- 游客记录按本地学习档案隔离；进入账号模式后避免在共享设备上泄露其他人的档案。
- 复习算法需纯函数、显式时间输入、版本标记；认识与客观拼写表现分别记录。
- 到期、失败、重复评分、跨日和时区处理具有明确测试。
- 设置每日新学目标与复习上限，避免积压时一次展示无限任务。
- 提供版本化 JSON 备份；导入前验证格式、预览合并，不直接覆盖现有记录。
- 存储不可用、配额不足、数据损坏时显示可操作错误，不假报保存成功。

## 5. 部署与离线（M2）

- GitHub Pages 为初期静态测试入口；正式启用账号前复核托管使用条件。
- 相对静态路径与 HashRouter 适配项目子目录，直接访问/刷新学习链接有效。
- PWA 支持安装和离线学习；首次加载后缓存应用壳和词库，处理升级、缓存失效。
- 源码与学习记录分离；学习记录不提交 GitHub。
- 检查移动设备、键盘导航、读屏标签、明暗主题、降低动画设置。

## 6. 认证与同步（M3）

- CloudBase v3 邮箱验证码认证，不把前端 userId 作为权限依据。
- 云数据库按服务端认证身份隔离，默认拒绝跨用户读写。
- 使用学习事件增量同步、唯一 ID 去重和游标；避免整份进度覆盖。
- 游客转账号前提供合并预览，认证成功后再归属，不覆盖已有云端历史。
- 未联网或云服务不可用时继续本地学习；事件排队、重试、显示失败与最后成功时间。
- 退出账号处理本机档案与待同步队列；提供隐私告知、数据导出、注销及删除流程。
- 浏览器仅可持有公开环境配置；服务端密钥不放前端或仓库。

## 7. 完成验收

- M0：七个页面可导航；类型检查、ESLint、基础测试、生产构建通过；报告实际审计局限。
- M1：正式词库来源与授权记录完整；学习/复习/拼写和刷新恢复可用；备份导入测试通过。
- M2：已验证部署 URL、子路径、移动布局、离线及更新行为。
- M3：手机和电脑登录同账号接续；重复与乱序上传不丢进度；断网后同步恢复。
- M4：两账号隔离、账号切换、注销、备份恢复、云服务暂停降级、朋友试用验证。

原站不可读或无源代码时，不声称还原；不同域名无法直接访问原站浏览器存储，迁移需要原站导出或认证后的专门迁移方案。
