# Codex 分阶段执行计划（重建版）

依据“开发思路”对话整理，非原附件全文。执行前阅读 SRS 和阶段报告；不假定之前的功能已完成。

## M0：项目审计与工程搭建

范围：检查源码、独立 React + TypeScript + Vite 工程、七个响应式页面、模块接口、TypeScript/ESLint/基础测试、README、实际安装与构建。

验收：导航、词卡预览、词库搜索、设置预览、空状态/未知路由测试通过；运行 typecheck/lint/test/build；记录原站和附件无法读取的局限。

**本轮完成 M0 后停止，不进入后续阶段。** 当前实现未获取完整词库、不保存学习记录、不部署、不接云账号。

## M1：词库与本地完整学习

状态：已实现，验收细节见 `docs/M1_REPORT.md`。M0 停止指令仅适用于上一轮，本轮由用户“继续”授权执行 M1。

1. 核实 ECDICT 等来源的词库许可，建立导入/校验脚本和来源文档。
2. Dexie 数据库及迁移、设置/事件/进度事务、存储失败处理。
3. 学习词卡、免费发音方案及兼容回退、拼写测试、错题。
4. 版本化间隔重复算法、每日新学与到期复习队列。
5. 统计真实学习事件；JSON 导出导入、验证与恢复。
6. 测试算法边界、刷新恢复、重复事件、备份损坏及合并。

验收：游客在本机可完整背词、复习、测试、保存、恢复；无服务器即可使用。

## M2：免费测试部署、移动体验与 PWA

状态：本地离线/更新、子路径验证和 GitHub Pages 发布已完成，见 `docs/M2_REPORT.md` 与 `docs/RELEASE_REPORT.md`。

1. 根据用户可用 GitHub 仓库设置源码和 Pages 工作流。
2. 验证子目录静态资源、刷新深链接、手机布局。
3. PWA 清单、应用/词库缓存、离线与升级提示。
4. 检查首屏资源、按需加载及可访问性。

验收：真实部署 URL 能访问，加载一次后断网可学习，更新版本不损坏学习记录。

## M3：CloudBase v3 邮箱认证与事件同步

状态：0.3.1 已部署免费环境后台和默认测试域名的邮箱登录入口，数据库 ADMINONLY 权限和无登录上下文拒绝已验证；103 项测试通过，包括 PWA 更新竞态、安全错误提示及元数据回写回归。认证网关 CSP 修复后，用户已确认真实邮件登录和首次同步成功。实机学习后的 PUSH 错误已复现为数据库 _id 回写，并已部署服务器修复；用户重试确认待上传队列归零。跨设备事件、离线重试与两账号权限仍待实机验收，M3 不能标记为完成。GitHub Pages 保留本地模式，因为实测免费体验环境拒绝添加该来源。见 `docs/M3_REPORT.md` 和 `docs/CLOUDBASE_SETUP.md`。

1. 核实当时官方 SDK、免费环境规则和邮箱能力；使用用户提供的免费环境配置。
2. 邮箱验证码、登录/退出/账号隔离；安全规则随代码记录。
3. 事件去重、增量拉取/上传、重试与状态；不使用全档案覆盖。
4. 游客档案合并预览、账号切换与离线缓存隔离。
5. 两设备、重复事件、并发修改、离线恢复测试。

验收：认证与授权分别验证，跨设备不丢记录；云端不可用时本地学习继续。

## M4：安全、恢复、朋友试用

1. 两账号权限验证、注销删除、隐私说明。
2. 数据备份恢复、架构版本迁移、云服务暂停降级。
3. 手机上实际体验，免费额度和环境续期维护说明。
4. 仅在有授权与可访问状态下分享/邀请试用，记录问题并修复。

## 下一轮可直接使用的指令

“继续完成 M3 真实环境接入。先阅读 M3 报告、CloudBase 配置说明与隐私报告；保留已验证的本地学习。用户只提供环境 ID、地域和 Publishable Key，按免费环境配置集合规则、索引、云函数和邮箱能力，再完成真实邮箱、两账号权限及双设备同步验收。不购买或升级付费服务，不把服务端密钥放进前端；没有免费环境时如实保留待验收状态。”
