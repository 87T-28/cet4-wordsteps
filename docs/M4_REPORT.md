日期：2026-10-11（Asia/Shanghai）。版本：0.3.3。用户继续授权完成不依赖第二个邮箱的检查；真实两账号隔离和独立测试账号的最终注销仍待验收。没有发送邀请或操作现用账号的删除。

## 服务端删除授权修复

发现旧 erase 接口仅检查登录身份，新的邮箱验证码验证由网页执行，直接调用函数可绕过网页确认。现已改为服务端核验当前访问令牌对应的用户信息，并与平台提供的 UID 比较；从该认证资料取得邮箱，使用已绑定用户目标 USER 明确指定收件人，服务端校验新验证码并完成官方 sudo 二次验证后才签发许可。客户端传入的邮箱或 verified 标记不作为授权依据；认证资料邮箱缺失或格式异常时，在发送和写入挑战前拒绝。

验证码挑战绑定 UID，5 分钟有效，60 秒内限制重复发送，最多 5 次校验；验证成功后挑战不可重放。短期删除许可只在客户端内存中持有，服务端保存其哈希及到期时间；每一页 erase 都验证同账号许可，缺失、伪造、跨账号、过期或异常到期字段均拒绝。元数据只写应用字段，继续避免数据库 _id 回写错误。

删除开始后保留原有删除标记，阻止旧会话上传；分批删除可在重新验证后继续。最后一页清除挑战 ID，保留哈希删除标记及用于短期重试的许可哈希/到期时间。邮箱、验证码、访问令牌、sudo 令牌和原始许可不写入数据库或日志。平台自身的日志/备份仍由 CloudBase 管理。

界面拆成“验证注销验证码”和最终“确认注销账号”。完成邮箱验证只取得短期许可，仍需输入确认文字并点击最终按钮才开始删除。CloudBase 身份注销使用服务端取得的官方 sudo 令牌。退出或重新请求验证码会清除本次客户端许可。

验证码和当前用户信息 HTTP 路径按已安装 SDK 3.10.2 的实际请求核对；仅访问运行环境专属认证网关，拒绝重定向，单次请求限时 8 秒，原始错误消息不回显。真实平台重新认证流程还需本人仅完成验证步骤确认；最终删除留给独立测试账号。

## 恢复验证

121 项测试、类型检查、ESLint、生产构建、PWA 和源码/构建隐私检查通过。新增测试覆盖上述授权、分步确认、迟到验证后的退出隔离、分页删除与许可续期、缺少主邮箱时拒绝、忽略伪造收件人、明确传入邮箱的 HTTP 契约、sudo 失败不签发许可，以及加密账号备份恢复后丢失上传回复的去重重试。

独立本机来源使用一条构造学习事件，验证加密导出内容、明确确认后清理测试档案、错误密码拒绝且不写入、正确密码预览并恢复。390px 设置页无整页横向溢出，资源记录仅含本机 HTTP 来源。没有读取、清理或导出真实线上学习档案。

原生下载事件未被浏览器工具捕获，因此未把实际文件落盘计入本次验收；通过导出 Blob 内容核对加密格式，并用其字节完成真实文件选择/导入流程。仅对测试页面捕获 Blob，应用 CSP 保持原有精确来源限制。
