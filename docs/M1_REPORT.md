## 复习算法约定

版本 `wordsteps-1`，属于简化间隔重复，不宣称完整实现 SM-2 或精确预测记忆。

| 评分 | 下一间隔 |
| --- | --- |
| 没记住，或客观拼写错误 | 10 分钟，正确连续次数归零，错误次数增加 |
| 有点难 | max(12 小时，上一次间隔 × 1.2) |
| 记住了 | max(1 天，上一次间隔 × 2) |
| 很熟悉 | max(4 天，上一次间隔 × 3) |

间隔上限 365 天，按绝对时长计算。事件按 ISO 时间和事件 ID 排序，乱序导入也可确定性重建。主观评分和客观拼写结果分别保存。

统计日期用设备当前时区。首次学习按词 ID 去重；日复习目标按词去重，累计复习按事件次数统计。连续学习从今天或昨天起向前回溯；没有拼写测试时正确率为空。

## 验证限制与阶段边界

- Tabbit 浏览器工具未触发 `download` 事件，无法确认文件保存到浏览器下载目录。已经验证实际 Blob JSON 内容、链接的 download 属性和真实页面导入流程。界面保留明确的“点击下载备份文件”链接，用户需确认本机文件保存。没有把工具事件等待超时声称为下载成功。
- 设备语音可能需联网或安装英语语音，未实测扬声器输出；发音失败显示音标回退。12 个词无上游音标，例句仅补充 6 个自编词条。
- 备份单文件上限 10 MB / 50,000 条事件；过大档案会明确拒绝生成不可恢复的文件，不改动本机记录。
- 数据所属地址和浏览器发生变化时需要手动备份迁移；清理浏览器数据可能丢记录。共用浏览器的人可以访问游客档案。
- 不包含 PWA 离线启动、GitHub 仓库/部署、邮箱登录或云同步。前述能力分别留给 M2/M3。
- 尚未取得原聊天附件全文或原站学习界面，原文档/视觉一致性仍不能确认。
