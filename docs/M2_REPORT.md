## 已实现

- Vite PWA / Workbox 生成安装清单、Service Worker 和预缓存。缓存应用壳、所有页面分块、完整词库、来源报告、许可证和图标，33 个条目，约 2.16 MiB。
- 180/192/512 像素安装图标；支持 standalone 清单和 maskable 图标。设置页提供安装入口与 Safari 添加到主屏幕说明；安装提示在入口提前捕获，不因晚进入设置而丢失。
- 离线资源准备状态、网络事件提示、每小时及回到前台/联网时检查新版本。
- 新版本等待用户确认；学习/复习页只提供返回首页更新入口。其它标签页激活新 Worker 时保留当前拼写答案，用户切换路由后载入新版，避免旧懒加载文件失效导致白屏。
- 更新仅管理应用资源缓存，不删学习数据库。使用唯一事件 ID 和原本的本地事务保存继续工作。
- 七个页面按需加载；React、数据库分包。手机导航增加滚动吸附。
- `.github/workflows/pages.yml`：main/master 推送、手动触发执行校验与 Pages 发布；PR 只校验；按 job 限定权限，构建采用 Pages base_path。
- PWA 清单/图标/预缓存校验脚本，及 `/wordsteps/` 子目录模拟服务器。
- 本地开发不注册 Worker；正式生产版本才启用 PWA，避免缓存干扰开发。

## 部署缺项

- 本地 Git 没有 remote，仍无首次提交；未修改 Git 历史。
- GitHub 连接可读取账号，但返回的可访问仓库列表为空；本机无 gh CLI。
- 已询问用户新建公开仓库 `cet4-wordsteps` 或提供已有仓库地址，尚未收到选择。预选项不视为提交或授权。
- 没有新建远程仓库、推送源码、启用远程 Pages 或执行远程工作流；因此没有可交付的真实上线 URL。
- 部署说明见 `DEPLOYMENT.md`，所有本地源码与工作流可审阅，下一步是按仓库选择发布并验证线上地址。

## 限制

- 浏览器网络模拟阻断请求时，Tabbit 中 `navigator.onLine` 仍为 true；离线验收依据未缓存请求失败和页面成功，而不是伪造网络状态。在线/离线事件的提示逻辑有自动化测试；真实设备的系统状态尚待确认。
- 未操作系统级安装对话框，未实测手机安装、设备语音或下载目录；已有安装清单及 UI 生命周期测试。M1 备份导出内容/导入流程已验证，但原下载事件捕获限制仍保留。
- 首次使用须在线，缓存完成后才能离线启动。浏览器清理/回收网站数据可能丢失缓存和 IndexedDB，仍需定期备份。
- 不同端口/域名的学习记录独立，迁移至线上地址时需要 JSON 导出导入；本轮验收数据只写入独立端口 4188。
- 云登录与同步仍未接入，不提前进入 M3。
