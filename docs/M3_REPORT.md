# M3 代码与待验收记录

日期：2026-10-11（Asia/Shanghai）。版本：0.3.0。

**M3 尚未完成真实环境验收。** 用户明确表示尚无 CloudBase 环境。本轮完成账号与同步代码、云函数、免费配置说明和本地验证；网站在无配置情况下继续提供完整的游客学习，不显示邮箱输入，不启动云认证或上传记录。

## 已实现

- CloudBase v3 邮箱验证码认证；保留 SDK 返回的 OTP 验证回调，不丢失验证码关联信息。前端 SDK 安装版本 3.10.2，服务端 SDK 3.18.3。
- 会话仅存本应用命名空间的 sessionStorage；只保存令牌、UID、邮箱和身份验证状态。退出停止同步、清除本应用会话、刷新 SDK 内存，并通知同环境同账号的其它标签页退出。
- 原游客数据库保持名称和内容，schema 2 增加已同步事件表。账号数据库按环境和 UID 分开，切换时不显示上一账号的快照。
- 首次登录先读取云端；游客档案提供事件数量及新增数量预览，明确确认才合并。先提交到账号缓存，再删除已转移的游客事件；重试去重，未转移事件保留。
- 学习事件增量同步：每次上传最多 50 条，拉取最多 200 条。服务端事务分配账号内顺序，事件 ID 去重，内容冲突拒绝，不整份覆盖档案。游标、远端事件和进度重建一起提交到本地事务。
- 待上传计数、同步成功时间和失败提示；前台定时、保存后、窗口恢复及联网时重试。会话世代检查阻止退出后迟到的结果切换档案。
- 云函数只使用平台提供的 UID；拒绝匿名、缺失身份、伪造 expectedUserId。客户端直接读写集合应全部禁止，服务端按本人 UID 查询。
- 注销需新验证码和 sudo 令牌；分批删除事件，再注销邮箱身份和清除本机账号缓存。失败会明确显示尚未完成。保留最少的哈希删除标记，阻止旧会话重新上传已注销档案。
- 配置缺失时不连云；配置后 CSP 只允许该环境的 API 来源。支持从 .env.local 或 CI 变量读取同一公开配置。打包、Git 和隐私检查排除秘密、备份及本机运行材料。

同步范围为学习事件及重建的进度、错词和统计。学习目标、界面设置暂按设备独立保存；云服务失败时本机学习和加密备份仍可使用。

## 本地验证

类型检查、ESLint 和 87 项自动化测试通过。测试覆盖既有学习、PWA 与备份，以及账号隔离、明确合并、迟到登录、身份缺失拒绝、事件重试去重、冲突事务回滚、游标分页、注销阻止上传等。

生产构建、词库、云函数白名单、PWA 和源码/构建隐私检查通过。独立浏览器档案在无配置生产版本验证：没有邮箱输入或云请求，词卡评分保存，离线刷新与恢复，390px 视口无整页横向溢出，没有页面脚本异常。真实邮箱和云权限尚未通过浏览器验证。

CloudBase SDK 为独立动态加载块，未配置时不初始化；PWA 会预缓存它，离线后仍有认证代码。SDK 压缩前约 864 kB，构建提示单块超过 500 kB，增加了初次离线缓存体积；不影响当前游客模式的身份边界。

0.3.0 已通过 GitHub Actions 发布至原网站；旧离线版本通过正常更新入口加载新版。线上无配置账号状态、学习词卡、移动布局、同源请求和 no-referrer 检查通过，未写入用户的真实游客档案。提交及工作流证据见 [发布记录](RELEASE_REPORT.md)。

## 隐私边界

源码与 Git 提交不含用户的登录邮箱、管理密钥、会话令牌或真实学习记录。测试仅用构造事件和无效测试身份。发布仍使用 GitHub noreply 作者地址。

启用后邮箱与会话由 CloudBase 处理；学习事件上传词 ID、评分、正确与否、时间、事件及随机设备标识，服务端按 UID 归属。游客档案不自动上传。云数据并非端到端加密，平台日志、备份与管理端权限由服务平台控制。本机缓存不做整库加密，共用设备应退出或清除账号缓存。

## 尚需用户免费环境

按 [配置说明](CLOUDBASE_SETUP.md) 创建明确为 0 元的免费体验环境，再配置邮箱能力、来源白名单、两集合的禁止客户端访问规则、索引和 wordsteps-sync 云函数。仅提供环境 ID、地域和 Publishable Key；不要提供身份证、登录密码、验证码、SecretId 或 SecretKey。

官方资源点文档：https://docs.cloudbase.net/quick-start/resource-point 。当前仍列出免费体验版每月 3,000 点，有能力与续期限制。若控制台没有免费选项，或邮件能力要求付费，不启用付费路径，继续本地模式。

真实环境必须验证邮箱发送与登录、平台 UID、同账号两设备同时学习及离线恢复、两账号权限、直接数据库访问拒绝、游客合并、注销与旧会话拒绝上传。模拟测试不能替代这些检查；全部通过后才算 M3 完成。
