## 已实现

- CloudBase v3 邮箱验证码认证；保留 SDK 返回的 OTP 验证回调，不丢失验证码关联信息。前端 SDK 安装版本 3.10.2，服务端 SDK 3.18.3。
- 会话仅存本应用命名空间的 sessionStorage；只保存令牌、UID、邮箱和身份验证状态。退出停止同步、清除本应用会话、刷新 SDK 内存，并通知同环境同账号的其它标签页退出。
- 原游客数据库保持名称和内容，schema 2 增加已同步事件表。账号数据库按环境和 UID 分开，切换时不显示上一账号的快照。
- 首次登录先读取云端；游客档案提供事件数量及新增数量预览，明确确认才合并。先提交到账号缓存，再删除已转移的游客事件；重试去重，未转移事件保留。
- 学习事件增量同步：每次上传最多 50 条，拉取最多 200 条。服务端事务分配账号内顺序，事件 ID 去重，内容冲突拒绝，不整份覆盖档案。游标、远端事件和进度重建一起提交到本地事务。
- 待上传计数、同步成功时间和失败提示；前台定时、保存后、窗口恢复及联网时重试。会话世代检查阻止退出后迟到的结果切换档案。
- 云函数只使用平台提供的 UID；拒绝匿名、缺失身份、伪造 expectedUserId。客户端直接读写集合应全部禁止，服务端按本人 UID 查询。
- 注销需新验证码和 sudo 令牌；分批删除事件，再注销邮箱身份和清除本机账号缓存。失败会明确显示尚未完成。保留最少的哈希删除标记，阻止旧会话重新上传已注销档案。
- 配置缺失或未启用时不连云；启用后 CSP 只额外允许该环境的区域 API 和认证网关两个精确来源。支持从 .env.local 或 CI 变量读取同一公开配置。打包、Git 和隐私检查排除秘密、备份及本机运行材料。

同步范围为学习事件及重建的进度、错词和统计。学习目标、界面设置暂按设备独立保存；云服务失败时本机学习和加密备份仍可使用。

## 隐私边界

源码与 Git 提交不含用户的登录邮箱、管理密钥、会话令牌或真实学习记录。测试仅用构造事件和无效测试身份。发布仍使用 GitHub noreply 作者地址。

启用后邮箱与会话由 CloudBase 处理；学习事件上传词 ID、评分、正确与否、时间、事件及随机设备标识，服务端按 UID 归属。游客档案不自动上传。云数据并非端到端加密，平台日志、备份与管理端权限由服务平台控制。本机缓存不做整库加密，共用设备应退出或清除账号缓存。
