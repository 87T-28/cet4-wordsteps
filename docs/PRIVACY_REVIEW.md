## 备份保护

使用浏览器 Web Crypto：AES-256-GCM、随机 16 字节盐、12 字节 IV、PBKDF2-SHA256（210,000 次）和固定附加认证数据。密码至少 8 字符，不保存到数据库、配置文件或网络。

每次导出使用新随机参数。错误密码或篡改会导致解密失败，不进入导入确认。仍校验版本、大小、词 ID、事件格式和冲突；旧明文备份兼容。解密后上限 10 MB / 50,000 条事件，加密文件上限 16 MB。

密码强度由用户决定，遗忘密码无法恢复。明文备份需自行保管。清除档案不会删除下载目录、云盘或他人已收到的备份，也不清除应用资源缓存。

## 审计事实

- 未发现你的登录邮箱、密码、令牌、个人主目录路径或真实学习记录写入可发布文件。Git 仍无提交与远程地址，没有已发布 Git 历史需要清理。
- 开发时为检查发布账号读取过 GitHub 账号资料，未写入源码、网站或源码包；此报告不重复账号资料。
- 源码 ZIP 排除 `.local`、node_modules、Git 元数据和学习备份。原 ZIP 在同一路径重新生成，移除原私有站点地址；已经下载到其它位置的旧副本不会自动更新。
- 锁文件的上游依赖警告包含维护者公开联系信息，不是你的邮箱。仅对依赖 `deprecated` 字段豁免邮箱匹配，其它规则仍扫描全文件，保留第三方原始元数据。
- 学习事件、设置和随机设备标识只保存在当前浏览器 IndexedDB，没有账号收集、自动上传、广告、第三方分析脚本或网页字体服务。
- PWA 缓存静态应用、公共词库、许可证和图标，不缓存学习事件或密码。
- 真实浏览器仅观察到测试网站自身请求；独立 4190 测试档案完成加密导出、错误密码拒绝、明确确认清除和成功恢复，未接触原学习档案。

## 验证

59 项测试通过，覆盖密文无学习词/密码、随机密文、错误密码/篡改拒绝、旧格式兼容、本地语音、清除数据库和 UI 确认。类型检查、ESLint、生产构建和 PWA 校验通过。

`npm run privacy:check -- --dist` 检查源码与构建中的已知格式，只报告文件名和类别，不回显潜在秘密。它不能识别任意私密文本或所有秘密格式。加密和 CSP 在真实生产浏览器验证通过，无页面脚本异常；未做完整渗透测试。

## 公开发布仍会涉及的信息

公开 GitHub 仓库和常规 Pages 地址会关联发布账号的公开用户名，源码和提交历史可见。之后提交应使用 GitHub noreply 地址，禁止把登录邮箱写入公开提交。当前还没有创建提交。

托管平台仍可处理访问 IP、浏览器信息和请求时间。HTTPS、同源策略和不上传学习记录不等于完全匿名，也不控制浏览器/操作系统自身的数据处理。

共用同一浏览器的人可以访问未清除的游客档案；当前 IndexedDB 不做整库密码锁定。密码加密保护导出文件，不能替代设备访问控制。

未来接入 CloudBase 时需更新认证隔离、隐私说明和网络策略，不能直接把开发工具读取到的邮箱当作站点登录账号。
