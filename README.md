## 本地运行

需要 Node.js 22.12+（或 24 LTS）及 npm。

```sh
npm ci
npm run dev
```

打开终端给出的地址，默认 http://127.0.0.1:5173/ 。停止服务器使用 Ctrl+C。

```sh
npm run typecheck
npm run lint
npm test
npm run data:check
npm run cloud:prepare
npm run build
npm run pwa:check
npm run privacy:check -- --dist
npm run preview
```

`build` 生成 `dist/`；`preview` 默认在 http://127.0.0.1:4173/ 预览生产版本。应用使用 HashRouter，刷新 `/#/learn` 等链接不需要服务器重写。构建支持相对路径或 `VITE_BASE_PATH` 指定项目子目录。GitHub Pages 工作流在 `.github/workflows/pages.yml`。

**开发服务器不启用离线缓存。** 要体验 PWA，请先 `npm run build`，再 `npm run preview`。首次打开保持联网，等待“离线资源已准备好”后再断网刷新。安装在设置中操作，或使用浏览器菜单；iPhone / iPad 使用 Safari 分享菜单添加到主屏幕。HTTPS 或 localhost 才能启用 Service Worker。

新版本不会在当前学习页自动重载；先评分保存，再返回首页更新。其它标签页启用新版后，当前答案仍保留，切换页面时安全加载新版。更新只管理应用资源缓存，不清空 IndexedDB。浏览器回收存储仍可能导致缓存与记录丢失，请保留 JSON 备份。

开发地址 5173、生产预览地址 4173 和未来线上地址属于不同来源，数据各自独立；切换地址前通过备份迁移。部署操作见 [部署说明](docs/DEPLOYMENT.md)。

## 当前可体验

- 七个页面导航，深链接与未知地址回退。
- 词卡回忆、设备朗读、按中文释义拼写；评分保存成功后再继续。
- 词库中英文搜索、未学/已学/错词/到期筛选，按批次展开列表。
- 每日新学与复习目标，设置、事件、进度持久化到 IndexedDB。
- 到期复习、拼写正确率、近期学习日、连续天数和薄弱词汇。
- JSON 导出下载、导入预览、确认合并、事件去重及损坏文件拒绝。
- 手机与电脑布局、系统明暗主题、键盘焦点和跳过导航。

未配置云环境时，学习数据属于当前浏览器和当前网站地址。刷新可恢复；不同设备或域名通过备份手动迁移。浏览器清理网站数据会删除记录，请定期备份。此时账号页不提供邮箱输入，也不发起云请求。

启用方式见 [CloudBase 免费环境配置](docs/CLOUDBASE_SETUP.md)。只使用环境 ID、地域、Publishable Key，服务端管理密钥不进入前端。登录需先确认数据说明，学习事件同步到本人账号；游客事件先预览并明确确认才合并。学习目标仍按设备设置。登录会话仅保留在本次标签页，退出切回游客档案；各账号使用独立本机缓存。注销需要新的邮箱验证码与文字确认。

发布前检查公开密钥的匿名角色、环境、地域和有效期，拒绝管理员密钥或个人登录令牌；本地声明校验不替代平台验签。仅配置三项公开值仍不会启用登录，还需要 `VITE_CLOUDBASE_ENABLED=true`，应在后台配置完成后设置。测试环境清空开发者云配置，避免单元测试向真实服务请求。

复习采用简化算法 `wordsteps-1`：没记住 10 分钟；困难至少 12 小时；记住至少 1 天；熟悉至少 4 天，后续按上一间隔增长，上限 365 天。拼写错误强制按“没记住”处理。日期按当前设备时区统计，间隔按绝对小时数计算。

语音仅使用 Web Speech API 中明确标记为本地的英语语音；没有本地语音时保留音标，不自动使用在线服务。词库有 12 个条目无音标，例句仅补充了 6 个自编词条。离线缓存包含应用、全部词库、懒加载页面和许可证。

备份默认使用密码加密（AES-GCM、PBKDF2），密码至少 8 个字符，仅在本机处理，不保存或上传；遗忘密码无法恢复。可显式选择明文导出，旧版明文备份仍能导入。解密后最多 10 MB / 50,000 条事件，加密文件最多 16 MB；未知词 ID、损坏/未来事件、冲突 ID 会拒绝导入。

设置页提供隐私说明和输入确认文字后清除本机档案的入口；清除本机档案不会删除云端或已下载备份。账号模式下清除缓存会同时退出。生产页采用 no-referrer；未启用云功能时仅允许同源连接，启用后只额外允许该环境的区域 API 和认证网关两个精确来源。未接入广告或追踪统计。公开 GitHub 发布会关联公开账号名，托管及认证平台仍可能处理访问日志。隐私边界见 [隐私报告](docs/PRIVACY_REVIEW.md)。
